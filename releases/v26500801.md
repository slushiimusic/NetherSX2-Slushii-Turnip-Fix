# v26500801 — Gameplay background-work preview

This update removes unnecessary work during ordinary gameplay with frame generation off. It keeps the Classic 3668 core, driver selection, game patches and saved settings from v26500800.

- Turning framegen off now removes its overlay and stops its twice-per-second monitor. A cold start with framegen off does not start that monitor. Enabling framegen and resolution-change recovery still start it when needed.
- Returning to a game applies OSD settings once. Later recovery checks only reload settings if the native emulator has actually changed the OSD preferences or an earlier apply failed. Older resume callbacks cannot apply settings in a newer session.
- FPS visibility and the user's all-stats-off choice remain supported. Flow stays 0.25 and artifact protection stays off. Framegen remains available on 60 Hz displays; this update does not change its saved switch position.

Install either APK over the existing Pink app without uninstalling or clearing data. FRAMEGEN and NONFRAMEGEN share the same package, signing certificate, memory cards and save states. The Daijisho connector from v26500800 remains compatible.

Automated checks cover monitor shutdown/re-enable, resolution recovery, redundant reload prevention, failed-apply retries and OSD preference repair. Both APKs pass signing, package/version, icon, settings layout and variant checks. The emulator core and FRAMEGEN LSFG library are byte-identical to v26500800.

This is a preview of specific background-work fixes, not a universal locked-60 claim. Game caps, patch compatibility, CPU/GPU load and storage activity still affect performance. Physical checks and measurement limits are recorded in the accompanying validation receipt.

On Nova, Ultimate Spider-Man launched from Daijisho with framegen off. Resolution changes in both 4:3 and widescreen, FPS ON/OFF, and restoring the current session passed. All eight existing save/card files and seven backed-up configuration files remained byte-identical; the current session was preserved in one previously empty save slot.

The initial widescreen camera-pan sample reported about 59.94 game FPS and two roughly 33 ms presentation intervals across 44 seconds, while a large SD-card transfer was active. These initial samples do not establish a clean before/after performance improvement.

Follow-up tests briefly paused the transfer and resumed it safely after each comparison. Hitches also occurred without the transfer. With framegen off, the best longer Nova sample used Sync To Host Refresh Rate, Host VSync and Threaded Presentation together: one 33.36 ms presentation interval across 109.28 seconds of camera movement in Ultimate Spider-Man at 1.5x and 4:3. Those timing settings were retained on the test Nova. A shorter zero-outlier result did not hold across longer tests, so occasional hitches remain and locked 60 is not verified. This follow-up changes only the test device settings and validation notes; the APKs and shipped defaults are unchanged. Thor, other games and sustained city traversal were not retested.
