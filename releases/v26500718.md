# v26500718 — FRAMEGEN and NONFRAMEGEN

Two matching Pink APKs for RP Nova and AYN Thor:

- **FRAMEGEN** retains optional frame generation. It requires a supported GPU and an active 120 Hz display mode. Flow scale remains 0.25.
- **NONFRAMEGEN** removes the Frame Generation row, DLL import prompts, native frame capture implementation and LSFG library. Existing framegen ON settings cannot activate it.

Both builds retain the same emulator, bundled drivers, game patches, Pink theme, internal-resolution controls and stock FPS OSD. Their differences are limited to the framegen build gate, its settings rows and runtime library.

## Changes

- Framegen suspends at 60 Hz without erasing the saved ON choice, and becomes available again at 120 Hz. The unavailable row now updates inside in-game settings dialogs as well as App Settings.
- Aqua theme colors are stored in the resources, so affected tab labels and stock dialog buttons no longer wait for the periodic recolor pass.
- Includes the recent FPS OSD persistence fixes, widescreen/internal-resolution recovery, redundant restart-dialog suppression and per-game aspect selection fixes.
- Retains the capture handoff, source timing and artifact protection changes from the Nova/Thor builds. Game-specific motion artifacts and framing issues can still occur with frame generation.

## Installation

Download **one** APK and install over Pink. Both variants have the same package and signing key; switching variants updates the existing app and retains its settings, save states and memory cards. Switching back from NONFRAMEGEN may require re-enabling Frame Generation.

## Validation

- Eight shared host checks and two NONFRAMEGEN checks passed.
- APK comparison verified that the emulator library, bundled drivers, patches and other assets are identical between variants.
- Both APK signatures match the existing Pink certificate. The final device check was interrupted when Thor disconnected; on-device gameplay validation of these release APKs is incomplete.
