# v26500722 — Fix missing icons and clarify the Classic base

Repairs the app icon and resolves the conflicting version information shown by the installer and GitHub.

## Changes

- Repairs the regular adaptive icon's background. The previous compiled vector was missing its viewport, group transforms and path attributes, which can prevent Android from loading the entire adaptive icon.
- Preserves the existing cube artwork and all five sizes of legacy launcher PNGs.
- Makes the installer's application name match the launcher: **NetherSX2 (Slushii's Turnip Fix)**.
- Corrects the README: the packaged emulator core is **NetherSX2 v2.2n-3668 (Classic)**, based on **AetherSX2 3668**. The previous 4248 description was incorrect. The core itself is unchanged.
- Keeps both **FRAMEGEN** and **NONFRAMEGEN** downloads. Artifact protection remains disabled at 60 and 120 FPS, and flow stays at **0.25**.

## Which version is this?

**v26500722** is this customized app's package/release version. **v2.2n-3668 (Classic)** is the underlying emulator core version. These are separate version numbers. The Classic lineage is documented at [Trixarian/NetherSX2-classic](https://github.com/Trixarian/NetherSX2-classic).

## Installation

Install the selected APK over the existing Pink app. The package and signing certificate are unchanged, so settings, save states and memory cards are retained. FRAMEGEN and NONFRAMEGEN replace one another in place.

## Validation

The new icon check reproduces the missing-viewport defect in v26500721. Both replacement APKs pass checks for compiled vector attributes, regular/round icon references, all legacy PNG sizes, matching installer/launcher labels, signatures and alignment. The emulator core, framegen library, drivers and patch assets are retained from v26500721. Testing on the affected Android device or launcher is pending because its model is unknown.
