# v26500723 — Control Settings tabs

Fixes the Control Settings tab strip being covered by the branded header. Header spacing now runs during layout for both Control Settings and App Settings, before the first visible frame. It no longer depends on a toolbar lookup or preference polling. Spacing follows rotation and system insets without accumulating extra padding.

## Downloads

- **FRAMEGEN** includes optional frame generation.
- **NONFRAMEGEN** removes framegen controls, capture runtime and the LSFG library.

Both APKs update the existing Pink package in place with the same signing certificate. Install one over your current Pink app to retain settings, save states and memory cards; do not uninstall or clear app data to switch variants.

For 30 → 60 FPS without a 60 FPS patch, use FRAMEGEN, turn **60 FPS Mode OFF**, restart the game, and leave **Frame Generation ON** on a supported GPU with an active 60 Hz or 120 Hz panel. The default multiplier is 2×, flow stays 0.25, and artifact protection remains disabled at both output rates.

The v26500722 icon and installer-name fixes are retained. The emulator core remains **NetherSX2 v2.2n-3668 (Classic)**, based on **AetherSX2 3668**. v26500723 is the custom package version. The reported Xenosaga Episode I stale-loading-image issue remains under investigation; this release does not claim a fix for it.

## Validation

- Layout regression checks cover both settings activities, late fragment inflation, first draw, rotation, platform-provided insets, hiding/restoring the header, replacement views and repeated draws without accumulating padding.
- Shared and NONFRAMEGEN host checks pass.
- Both signed APKs pass package/version, signature, alignment, launcher icon/name and variant-content checks.
- The existing emulator core, LSFG library, drivers, game patches and tab/pager layout resources are retained.

No handheld installation or visual confirmation was performed for this update. No device settings, save states or memory cards were accessed or changed.
