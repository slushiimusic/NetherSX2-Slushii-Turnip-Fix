# v26500719 — Framegen at 60 Hz

The FRAMEGEN build now allows **60 Hz and 120 Hz** display modes. At 60 Hz, Frame Generation stays available in App Settings and in-game settings.

## 30 → 60 FPS setup

1. Turn **60 FPS Mode OFF** and restart the game so the patch is no longer applied.
2. Turn **Frame Generation ON**. The panel can now stay at **60 Hz**.
3. Keep the default **2×** multiplier and **0.25** flow scale.

A game rendering at 30 FPS can output approximately 60 FPS while its simulation stays at 30 FPS. Interpolation artifacts can still occur.

## Changes

- Removes the 60 Hz settings restriction and runtime suspension. Supported-GPU checks remain in place.
- Uses the active physical display mode for output pacing. A panel set to 60 Hz no longer inherits a 120 Hz cap from its maximum supported mode.
- Updates pacing live when switching between 60 and 120 Hz, without rebuilding the interpolation context. Saved caps cannot exceed the active panel rate.
- Includes matching **FRAMEGEN** and **NONFRAMEGEN** APKs. NONFRAMEGEN continues to omit framegen controls, capture implementation, DLL prompts and the LSFG library.

## Installation

Install your chosen APK over Pink to retain settings, save states and memory cards. Both variants have the same package and signing certificate and replace one another in place.
