# v26500721 — Artifact protection disabled at 60 and 120 FPS

The FRAMEGEN build now has artifact protection completely disabled. Movement and scene changes no longer cause this protection to replace generated frames with repeated real frames, whether outputting 60 or 120 FPS.

## Changes

- Removes the artifact detector, its frame-suppression path and its two-pair recovery delay.
- Ignores older saved `fg_anti_artifacts=on` settings. The native compatibility setter also cannot re-enable protection.
- Keeps flow scale at **0.25**, the default **2×** multiplier, and support for active **60 Hz or 120 Hz** display modes.
- Includes matching **FRAMEGEN** and **NONFRAMEGEN** APKs. The emulator core, drivers, patches and other settings are retained.

Interpolation warping and scene-cut artifacts may be more visible with protection removed. Generation still depends on normal runtime requirements and GPU availability.

## 30 → 60 FPS setup

Turn **60 FPS Mode OFF**, restart the game, and leave **Frame Generation ON**. A native 30 FPS game can then output approximately 60 FPS, including with the panel set to 60 Hz. The same default 2× multiplier supports 60 → 120 FPS with a 120 Hz panel when performance allows.

## Installation

Install your chosen APK over Pink to retain settings, save states and memory cards. Both variants share the same package and signing certificate and replace one another in place.

## Validation

- Seven shared host checks and two NONFRAMEGEN checks passed, including loading legacy ON settings at both supported refresh rates and preserving flow at 0.25.
- Rebuilt the native framegen library and checked that its compatibility setter does nothing; the artifact-fallback path is removed. JNI exports and native dependencies are preserved.
- Both APKs passed signature, alignment and variant-content checks. The emulator core, drivers and patches match v26500720.
- New on-device gameplay and visual validation is pending. No device installation, setting changes or save-file operations were performed for this release.
